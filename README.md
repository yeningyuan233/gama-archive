# GAMA Archive 0.2.3

0.2.3 在完整继承 0.2.2 的基础上加入本地身份与许可资历系统。

- 本地身份：自定义 Operator ID、昵称与本地口令；不进行网络同步。
- 口令只保存本地摘要，不写入明文。
- 自然许可等级由有效访问时间累计：L0 即时、L1 约 1 小时、L2 约 6 小时、L3 约 24 小时。
- 仅在本地身份已认证、页面位于前台且近期存在活动时累计许可资历。
- 临时权限覆写 ON：保留原有 L0–L3 手动选择；OFF：镜像访问等级跟随自然许可等级。
- 权限覆写不暂停许可资历账本；账本保留正负调整接口供后续档案机制使用。
- 本地终端设置同时提供 GAMA MIRROR 连接 / 终止开关。
- 退出镜像继续清理临时会话状态，但不删除本地身份、昵称或许可资历。
- 公开站与 GAMA 顶栏均使用无字母图标，原有名称保持不变。
- iOS Portable 同步支持本地身份、自然许可、覆写与镜像设置。

入口：
- START_HERE.html：桌面 / Android
- IOS_START.html：iPhone / iPad
